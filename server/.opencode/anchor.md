# Deployment Pipeline — دارين السابعة

## Architecture

```
Browser
    │
Node API (Express + Prisma)
    │
────────────────────────────────────
│ Prisma ORM
│ Redis + BullMQ (planned)
│ PostgreSQL
────────────────────────────────────
```

## Deployment Scripts (`deploy/`)

| Script | Function | Status |
|--------|----------|--------|
| `00_preflight.js` | فحص البيئة (Docker, DB, مساحة, إعدادات) | ✅ Ready |
| `01_backup.sh` | نسخ احتياطي (SQLite, PostgreSQL, env, uploads) | ✅ Ready |
| `02_migrate.sh` | تشغيل PostgreSQL + push schema + data migration | ✅ Ready |
| `03_run_verify.sh` | تشغيل التحقق 4 مستويات، يقرر: switch/block | ✅ Ready |
| `04_switch.sh` | تفعيل الخدمة (validate, verify, build, health, smoke, nginx) | ✅ Ready |
| `05_post_deploy_monitor.sh` | 10 دقائق مراقبة + auto-rollback | ✅ Ready |

## Verification Module (`server/scripts/verify/`)

| Module | المستوى | Checks |
|--------|---------|--------|
| `dataIntegrity.js` | 1 | COUNT, SUM, MIN/MAX لكل جدول |
| `relations.js` | 2 | Foreign key orphan check (16 علاقات) |
| `apiSmoke.js` | 3 | Login → CRUD → Auth → Upload → Cleanup |
| `performance.js` | 4 | Baseline comparison (0-20%✅/20-50%⚠️/50%+❌) |
| `report.js` | Score | نتيجة مئوية + قرار (≥98% allow, 95-98% warn, <95% block) |
| `index.js` | Orchestrator | يشغل الكل ويقرر exit code |

## Prisma Schemas

| File | Provider | Use |
|------|----------|-----|
| `server/prisma/schema.prisma` | PostgreSQL | Single source of truth (all environments) |
| `server/prisma/migrations/` | PostgreSQL | Baseline + delta, applied via `prisma migrate deploy` |
